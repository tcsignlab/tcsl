Google Maps API Key Required

This tool uses Google Maps satellite imagery to measure paved areas and roofs. You need a free API key — Google gives $200 free credit/month (more than enough for business use).

  1. Go to console.cloud.google.com
  2. Create a project → Enable Maps JavaScript API + Geocoding API
  3. Go to Credentials → Create API Key
  4. Paste your key below and click Load Map

Your key is stored locally in your browser and never sent anywhere.
