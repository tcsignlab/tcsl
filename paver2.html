Google Maps API Key Required

This tool uses Google Maps satellite imagery to measure areas and generate quotes. You need a free API key — Google provides $200/month free credit, more than enough for business estimating.

  1. Go to console.cloud.google.com
  2. Create project → Enable Maps JavaScript API, Geocoding API, Maps Static API
  3. Credentials → Create API Key
  4. Paste key below and click Load Map

Key saved in your browser only — never transmitted elsewhere.
