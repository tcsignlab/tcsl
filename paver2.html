Google Maps API Key Required

Liberty Paver Estimator uses Google Maps satellite imagery to measure property areas. You need a free API key — Google gives $200/month free credit, more than enough for business quoting.

  1. Go to console.cloud.google.com
  2. Create a project → Enable Maps JavaScript API + Geocoding API + Maps Static API
  3. Credentials → Create API Key
  4. Paste below and click Load Map

Key saved in your browser only — never shared.
